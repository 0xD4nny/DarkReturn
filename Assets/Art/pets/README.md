# Altar pet portraits

Generated on 2026-11-18 using the built-in image_gen tool. Four original PNG assets with alpha transparency; generated files were copied unchanged into this directory. Existing hero idle portraits served only as style references.

The `portrait` field in `data/config/pets.json` selects the large altar image and selection thumbnail. The separate SVG `asset` field remains the inventory/enchanting icon.
