# Archiv der ersetzten Icons

Hier liegen Symbole, die nach dem Wechsel der Icon-Auswahl nicht mehr im Spiel verwendet werden.

- `000000/transparent/1x1/`: bisherige Pack-SVGs mit erhaltener Urheber- und Ordnerstruktur. Nur Icons ohne verbleibende Laufzeitreferenz werden hierher verschoben.
- `inline/`: die vorherigen, direkt in `index.html` eingebetteten Navigationssymbole als eigenständige SVGs. Linienbreite und Linienenden sind für eine spätere Wiederverwendung mitgespeichert.

Weiterhin verwendete Symbole bleiben im aktiven Icon-Verzeichnis, auch wenn sie an einzelnen Stellen ersetzt wurden. Es werden keine Originaldateien aus dem externen Icon-Pack entfernt oder verändert.

Die Lizenz und die ursprünglichen Urheber der Pack-SVGs stehen in [license.txt](../license.txt). Prüfsummen und Archivpfade stehen in [manifest.json](../manifest.json). Das Spiel lädt keine Dateien aus diesem Archiv.
